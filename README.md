# AI coding design templates

Templates and setup files that make AI coding tools build interfaces that look professional: **CLAUDE.md templates, Claude Code skills, agents and hooks, Cursor rules and AGENTS.md**, focused on design.

AI coding tools like Claude Code, Cursor, Codex, Lovable and Bolt write good code, but without a design to follow they all produce the same generic look. The fix has two parts:

1. **A design template**: a finished page the tool copies. Browse 560+ at [BrowserMoon](https://www.browsermoon.com).
2. **Setup files**: rules the tool reads every session, so it keeps following that design.

This repo explains the setup files for each tool, with structures, examples and best practices.
